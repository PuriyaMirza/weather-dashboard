# Weather Dashboard

Milestone 1 foundation for a weather dashboard built with the Next.js App Router, TypeScript, Tailwind CSS, Zustand, current dnd-kit packages, Recharts, Zod, Vitest, and Playwright.

## Getting started

```bash
npm install
npm run dev
```

Open <http://localhost:3000> to view the accessible placeholder dashboard page.

## Validation

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Scope

This branch intentionally implements Milestone 1 only. Milestone 2 features such as live weather data, dashboard persistence, drag-and-drop widgets, and production charts are not included yet.
